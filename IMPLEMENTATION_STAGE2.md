A fonte de tipos/validações é `shared/ultra.ts`. Não editar arquivos fora de seu escopo quando houver agentes concorrentes. Backend REST Express (não obrigatório usar tRPC para features); frontend faz fetch relativo, JSON, credentials include, `X-Ultra-Request: 1` e em mutações autenticadas `X-CSRF-Token` vindo de `/api/auth/me`. Todos os resultados da API são JSON diretos; erros `{error:string,code?:string}` com status apropriado. Não imprimir segredos.

## Auth (agente responsável)
`drizzle/authSchema.ts` exporta novas tabelas; importar `users` de `drizzle/schema.ts` se necessário. Parent reexportará tabelas e gerará migração. Manter users intacta: conta nova recebe `openId` aleatório `ultra:<uuid>`, email é associado em identidade única. `server/ultra/auth.ts` exporta `getSession(req): Promise<{user: PublicUser, csrfToken: string} | null>`, `requireSession(req,res,next)` populando `(req as UltraRequest).ultra`, `requireMutation(req,res,next)`, `logout(req,res)`, tipo `UltraRequest` e `createSession(userId,res)`. `server/ultra/authRoutes.ts` exporta `registerAuthRoutes(app)`.
GET `/api/auth/me` -> AuthResponse; POST `/api/auth/signup` {name,email,password} e `/api/auth/login` {email,password} -> AuthResponse; POST `/api/auth/logout` -> {success:true}; PATCH `/api/auth/profile` {name} -> PublicUser; POST `/api/auth/google/start` {origin:window.location.origin} -> {url:string}; GET callback `/api/auth/google/callback`. Google Client ID/Secret estão configurados, não imprima valores. OAuth: validar ID token com jose + Google JWKS, iss/aud/nonce/email_verified/sub, single-use browser-bound state cookie/DB and PKCE. Popup callback pode postar `{type:'ultra-auth-complete'}` para a origin que iniciou e fechar ou mostrar link fixo `/app`. URL pública é passada pelo browser, nunca internal Host. Cookies HTTPS Preview None+Secure independentemente de NODE_ENV. Custom header JSON impede CSRF nos endpoints não autenticados; demais mutações com token de sessão. Não criar bypass Manus/Preview. O ctx tRPC deve usar sessão Ultra e logout dela, não OAuth starter.
